# Marrow & Hide — E-Business Final Project

A full-stack e-commerce web application for a luxury leather goods brand (bags, wallets, belts, outerwear), built with React (frontend) -> Node.js/Express (backend) -> MongoDB (database).

This satisfies the Final Project's minimum technical requirement of Frontend -> Backend -> Database with full CRUD, and carries forward the customer-registration validation logic and security technique (input sanitization) from the earlier Mid Project's PHP form.

See server/ and client/ for the backend and frontend. Run `npm install` then `npm run seed` and `npm start` in server/, and `npm install` then `npm run dev` in client/. Set MONGO_URI in server/.env.
